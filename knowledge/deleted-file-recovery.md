# Recovering a deleted or overwritten file

Files stored in the sync client can be restored by the person who deleted them,
without a ticket. The recycle bin in the web interface holds deleted items for
93 days, and version history keeps previous versions for 30 days even if the
file was overwritten rather than deleted.

Version history is the one people forget. If a document was saved over rather
than deleted, the recycle bin will be empty and the file still recoverable.

Files saved only to the desktop or to a local folder outside the sync client
are not backed up at all. If the machine has been rebuilt, they are gone.

Shared files deleted by someone else go to that person's recycle bin, not
yours, so ask them first.
