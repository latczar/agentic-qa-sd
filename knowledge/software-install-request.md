# Installing software on a work laptop

Standard applications are available from the company portal and install without
approval. Open the portal, search for the application, and choose install. No
admin password is needed.

Anything not in the portal needs a licence check and a security review first.
Submit the request with the vendor name and what the software is for. Reviews
typically take three working days, longer if the vendor has not been assessed
before.

Installers downloaded directly from the web are blocked by device policy, and
repeated attempts are flagged to security. That is the policy working, not a
fault.

Software needed urgently for a customer commitment can be escalated by your
line manager, which shortens the review rather than skipping it.
